# رادار Pre-Pump — نسخه اولیه اندروید

## قابلیت‌ها
- رابط فارسی راست‌چین و سازگار با موبایل.
- دریافت آمار عمومی بازار نوبیتکس و تطبیق نمادهای آن با جفت‌ارزهای USDT بایننس.
- تحلیل کندل‌های بسته‌شده ۱۵ دقیقه‌ای؛ حجم آخرین کندل در مقایسه با ۲۰ کندل قبل، رشد ۲۴ساعته، کف‌های اخیر، فشردگی، مقاومت، حجم دلاری و جهت ساده بیت‌کوین.
- ایمیل فقط برای امتیاز بالاتر یا مساوی آستانه (پیش‌فرض ۷۵) و فقط پس از تأیید بازار نوبیتکس.
- لینک TradingView همان نماد در تایم‌فریم ۱۵ دقیقه‌ای.
- جلوگیری از ارسال تکراری برای همان نماد و همان کندل.
- این ابزار معامله‌ای انجام نمی‌دهد.

## راه‌اندازی روی گوشی
این بسته یک PWA است، نه APK نصب‌شدنی مستقیم. برای نصب به‌عنوان اپ:
1. فایل‌ها را روی یک هاست استاتیک HTTPS بارگذاری کن (مثلاً GitHub Pages یا Netlify).
2. در Chrome اندروید آدرس را باز کن و از منوی سه‌نقطه «Add to Home screen / نصب برنامه» را بزن.
3. اینترنت لازم است. ابتدا «اسکن همین حالا» را امتحان کن.
4. اگر مرورگر خطای CORS برای API نوبیتکس نشان داد، هیچ ایمیلی ارسال نمی‌شود. در آن حالت باید یک واسط API امن راه‌اندازی شود؛ نصب PWA این محدودیت را رفع نمی‌کند.

## تنظیم ایمیل با EmailJS
این نسخه رمز ایمیل یا کلید خصوصی نمی‌خواهد. باید حساب EmailJS بسازی و مقادیر Service ID، Template ID و Public Key را وارد کنی.
1. یک Email Service متصل کن و یک Email Template بساز.
2. در فیلد To Email قالب، `{{to_email}}` بگذار.
3. Subject قالب را `{{subject}}` قرار بده.
4. بدنه قالب می‌تواند این متغیرها را داشته باشد:
   `{{symbol}}`, `{{score}}`, `{{price}}`, `{{change24h}}`, `{{volume_ratio}}`, `{{candle_change}}`, `{{nobitex_market}}`, `{{trigger}}`, `{{invalidation}}`, `{{resistance}}`, `{{chart_url}}`, `{{timestamp}}`, `{{score_note}}`
5. شناسه‌ها را در برنامه وارد کن، «ذخیره تنظیمات» و «ارسال ایمیل آزمایشی» را بزن. بعد از دریافت تست، اسکن را اجرا کن.

## محدودیت‌های نسخه اول
- اسکن خودکار هر ۱۵ دقیقه فقط در حالی قابل اتکاست که صفحه باز و فعال باشد؛ اندروید ممکن است تایمر پس‌زمینه را متوقف کند. برای پایش شبانه‌روزی واقعی به سرور همیشه‌روشن نیاز است.
- API عمومی نوبیتکس ممکن است از مرورگر به‌خاطر CORS در دسترس نباشد. برنامه در این حالت fail-closed است و ایمیل نمی‌فرستد تا بازار نوبیتکس قابل تأیید باشد.
- برای کاهش درخواست‌ها، حداکثر ۶۰ جفت‌ارز مشترک با حجم بالا اسکن می‌شوند.
- Funding، داده مشتقات و اخبار/کاتالیزورها در نسخه اول لحاظ نشده‌اند. امتیاز فنی، احتمال سود نیست.
- قیمت و حجم داخل ایمیل از داده بایننس است؛ وجود بازار نوبیتکس جداگانه تأیید می‌شود. پیش از معامله قیمت و نقدشوندگی خود نوبیتکس را کنترل کن.

## منطق امتیازدهی
وزن‌های قابل اندازه‌گیری در این نسخه: جهش حجم ۲۵، کف‌های بالاتر و فشردگی ۱۵، قیمت همراه حجم ۱۵، مقاومت ۱۰، نقدشوندگی ۱۰، وضعیت ساده BTC پنج. بخش‌های موجود جمعاً ۸۰ امتیاز خام دارند و به مقیاس ۱۰۰ نرمال می‌شوند. Funding و اخبار هنوز محاسبه نمی‌شوند.
